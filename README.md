# NexaStudio — Multilingual Landing Page

A fully functional, multilingual landing page for NexaStudio, a fictional design agency. Built with Next.js 16, TypeScript, Tailwind CSS v4, and next-intl.

## Tech Stack

```
✅ Next.js 16 + TypeScript + Tailwind CSS v4
✅ next-intl — 3 dil (az/en/ru), URL routing
✅ Sticky scroll-aware Header + LanguageSwitcher
✅ 5 sections: Hero, About, Services, Portfolio, Contact
✅ Framer Motion animation (whileInView, stagger)
✅ React Hook Form + validation
✅ Reusable components — Button, Badge, SectionHeader
✅ ScrollToTop buttob
✅ Fully responsive (mobile & desktop)
✅ README.md
```

## Getting Started

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser. You will be automatically redirected to `/az`.

## Build

```bash
npm run build
```
